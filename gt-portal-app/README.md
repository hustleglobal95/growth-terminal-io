# Growth Terminal Portal

The standalone client portal for [Growth Terminal](https://growthterminal.io), the system
that finds the single constraint capping a business's revenue, prices the fix, and grades
every call against real revenue. Diagnosis, not a dashboard. Priced, not guessed.
Verified, not vibes.

One console: every analysis, every client, every teammate. Each diagnosis reads two ways,
an Overview for the decision and a Deep dive that turns the 90 day plan into thirty
execution steps, each with its method, inputs, finish line, owner and failure mode.

Built with React, Vite and TypeScript. Ships as static files, installs on phones as a PWA,
and runs in demo mode with a full sample workspace until the live API is wired. See
DEPLOY.md for the ten minute path to app.growthterminal.io.
